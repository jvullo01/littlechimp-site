# littlechimp-site

Static support and privacy pages for **LittleChimp**, an iPhone app by Jamie Vullo. Served by GitHub Pages from this public repo (`jvullo01/littlechimp-site`, branch `main`, root folder).

- `index.html`: small landing page linking both pages
- `privacy.html`: privacy policy (https://jvullo01.github.io/littlechimp-site/privacy.html)
- `support.html`: support FAQ and contact (https://jvullo01.github.io/littlechimp-site/support.html)

Plain HTML with inline CSS. No scripts, analytics, trackers, cookies, web fonts or CDNs. Nothing is loaded from anywhere else; the only outside link is Apple's privacy policy.

Before going live, replace the highlighted placeholders:

Publish: create the public repo, push these files, then Settings → Pages → Deploy from a branch → `main` / root. Check that both URLs load before entering them in App Store Connect.
